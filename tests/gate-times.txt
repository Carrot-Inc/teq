# How long each suite of tests/gate.sh and each of its comparison lines takes on a remote machine, in seconds, as
# its last run with --record whose every line passed measured them; the gate deals the suites out to the machines by
# these times, longest first, so that the machines end together, and spreads the comparison lines by them. A suite
# or line missing here counts as 120. A suite the gate runs as pieces (`pieced` in tests/gate.sh) has a row for each
# piece, `<suite>.<k>/<n>`, which --record writes, never the suite's own row (left as it was), whose time divided by n
# a piece without a row of its own counts; a piece's row under another n of its suite goes at the next --record.
# A project line's row is its time on the machine holding its checkout, which the gate's dealer reads for the projects'
# chains (their first rows the longest of three runs of each chain on one holder, at host loads of 8 to 77).
# A row `<line>` is its seconds on a machine of eight CPUs, `<line>@<n>` on one of n (the dealer charges a line at its
# shard's kind, the row of eight where its kind has none; --record writes each kind's own row). A row a kind never
# measured is estimated from the other kind's by its family's ratio and said so in a comment line above it.
# A machine whose look names a kind (GATE_KIND in its own login environment, a machine of another host) has its own
# rows, `<line>@<kind>`, which --record writes as its run, or, where that machine's start read a CPU pressure over 40
# or none (its host busy), as the larger of the run and nine tenths of the row it replaces; a line
# with no such row is charged its row of eight over the kind's `speed@<kind>` (percent of an eight-CPU machine's
# speed), and the kind's shards start from `head-wait@<kind>`. `<line>@<kind> -1` keeps the line off that kind, which
# the gate prints; no gate measures it there while the row stands, so the row is taken out by hand once what kept the
# line off is gone, and a gate with --record writes the kind's row.
# `head-wait` is no line: the seconds the shards past the builder's start their suites after the builder's shard
# does (the builder builds the head, the others wait for its binary), by which the dealer starts their loads. It is
# written from gates' lines (each shard's seconds less its suites'), --record keeping it as it is.
