# The forms of a library's compile options (compile.c.options and compile.cpp.options of its scala-native.properties)
# the native build takes, read by src/native/library_options.rs and by the suite tests/native-build.scala: each form one
# token zig 0.16.0 takes no argument after, given to zig as it is (`kept`); or an option of clang's that writes or
# shapes a dependency output, left out with its value (`dropped`, the value in the token; `dropped+next`, the value the
# token after it), as the compilation's list of what it read is the build's own (`-MD -MF <list> -MQ <object>`,
# src/native/build.rs). Any other option of a library's is refused by name. tests/native-build/library-options.scala
# checks every row against zig's option table (src/clang_options.zon at zig's tag) and writes the cases the suite
# builds from it. The kept forms: `-std=` and `-fcxx-exceptions`, which the descriptors of the libraries published for
# Scala Native 0.5 hold (Scala Native's own and sn-sizemap's, the only ones with options), and `-D`, `-U` and `-I`, the
# spellings the build itself gives a descriptor's defines and include paths. The dropped ones are clang 21.1.0's
# dependency output options a compiler driver takes (clang/include/clang/Driver/Options.td: the M group, the options
# marshalled into DependencyOutputOptions, the driver's dependency outputs, their aliases).
#
# <form> <role> <zig's entry> <its kind> [<field>]...
#   form   a token as it is written, or `<prefix>*`: the prefix and a value that is not empty
#   field  `!<value>` or `!<start>*`: a value the form does not take (one by which zig takes another entry);
#          `c:<value>`, `cpp:<value>`: a value the suite builds the form with, in C or C++; `cpp`: a token the suite
#          builds in C++
